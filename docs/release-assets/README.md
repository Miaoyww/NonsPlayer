# 发布头图

`header-1.0.0.png` 是可直接上传的 1600 × 800 发布头图。`header.svg` 是可编辑矢量源文件，文字与背景为独立元素；左上角使用项目 `docs/app-icon.png`，右侧叠放真实发现页与音乐库截图，图片内嵌在 SVG 中，无外部图片或字体依赖。

## 下次更换版本

双击打开 `editor.html`，修改版本号、说明、平台与发布类型，点击“下载 PNG”或“下载 SVG”。无需安装工具或启动本地服务，导出尺寸固定为 1600 × 800。长文案请先检查预览是否超出左侧区域。

编辑器首次加载显示 v1.0.0；每次修改后请下载 SVG 保存修改结果，编辑器不会自动写回仓库文件。新的 SVG 可通过编辑器的“载入 SVG”重新打开，继续调整。版本号建议保持 `v1.0.0` 这样的短格式。

也可以直接用文本编辑器或矢量设计软件打开 `header.svg`：`version`、`subtitle`、`platform`、`release-kind` 分别对应版本号、副标题、平台与发布类型。`title`、`desc` 是图片的无障碍描述，应与内容同步修改。

背景采用蓝白纯色与留白；左上角保留项目原始图标的外观，右侧截图采用轻微倾斜与错位叠放。`discovery.png` 与 `library.png` 保留原始截图，截图也内嵌在 SVG 与编辑器中。字体优先使用 Segoe UI 和微软雅黑；不同系统的字体替代可能略微改变字形，PNG 保留导出时的外观。
