# WASM 适配器执行与组合模块

当前外部音乐适配器与功能插件共用 `infrastructure/wasm_runtime.rs` 执行器，分别由各自管理器提供 Host 上下文。执行预算按调用类型选择，不按音乐平台、源码语言或包名选择。

## 临时适配器预算（2026-10-14）

用户授权先验证聚合适配器，再根据测量收紧预算。当前实现如下；数值是硬上限，不代表实际消耗或性能保证。

| 项目                               | 普通功能插件 | 外部音乐适配器 |
| ---------------------------------- | ------------ | -------------- |
| Component 文件                     | 16MiB        | 32MiB          |
| Store 总线性内存                   | 64MiB        | 256MiB         |
| memory 数量                        | 1            | 4              |
| 初始化／每次 call fuel             | 1000 万      | 1 亿           |
| 实例化／初始化／每次 call 单独期限 | 5 秒         | 15 秒          |
| 单次 JSON 参数／响应               | 64KiB        | 64KiB          |
| instances／tables／每 table 元素   | 16／8／10000 | 16／8／10000   |

ResourceLimiter 汇总多个线性内存的增长量，不能让每个 memory 分别占满 256MiB。失败的实际分配回退预留量，超过总额立即 trap。该额度不覆盖编译器、宿主堆、表、虚拟地址保留或整个应用进程的内存；Store 内实例失效后不通过另建实例回收额度，整个 Store 释放后才结束其额度周期。

epoch 按既有 10 毫秒 tick 对齐预算，墙钟 timeout 仍独立执行；有更短业务请求期限时，以更早的期限取消。现有 AdapterManager 的部分业务为 12 秒，临时运行时 15 秒不延长这些业务，也不修改查询／播放并发数量。停用、账号切换与取消规则保持作用。

## Rust 密码组件

`packages/wasm-crypto` 用 RustCrypto 实现通用密码原语，作为适配器的内部依赖，构建时通过 WIT 组合。不增加宿主密码方法或任何平台专用签名操作，JS 协议代码仍负责调用顺序、认证字段与平台规则。算法、输入限制和构建方式见 [密码模块说明](../packages/wasm-crypto/README.md)。

组合后的 Component 对宿主继续提供现有 initialize/shutdown/call，内部密码接口不再是外部导入。语言运行时及所有子模块都计入同一适配器文件大小、Store 总内存、fuel 和期限。安全随机数、HTTP、计时器与 WebSocket 仍需要分别验证并按受控通用能力提供，密码模块不代表这些能力已经完成。

这一阶段未注册可用 QQ 来源，未接入真实账号、扫码或完整音乐协议；不能把密码模块测试描述为第二适配器已经可用。

## 验证范围

Windows x64、Rust 1.95.0、Wasmtime 46.0.1、ComponentizeJS 0.23.0、jco 1.37.0、wac 0.12.0。公开固定向量聚合探测在仓库共享执行器连续三次通过；探测产物12,151,969字节，debug加载含编译约204秒，调用约4.09／2.98／2.90毫秒。重现脚本位于密码模块，源码归档后重新构建的fixture为12,159,174字节，外部导入检查及快速Wasm对照通过。此处不把debug编译时间作为Release实例化成本，也没有测量实际线性内存峰值、逐算法fuel或完整协议性能。

宿主库回归175项通过、4项既有测试忽略，覆盖既有外部适配器、账号、缓存、播放与插件。新增执行器测试验证跨memory总额、普通插件memory数量和失败分配回退；外部音乐fixture的越界分配同步改为超过256MiB，普通插件fixture维持超过64MiB。Rust密码模块3项测试和1项文档测试通过，严格Clippy通过。宿主Clippy仍有歌词与播放核心的既有警告，本轮不修改它们。格式检查通过。

未执行macOS/Linux原生构建、真实音频播放、真实平台账号、WebView释放或Release性能验收。共享HTTP、安全随机数、时钟、计时器、WebSocket、完整协议接入及平台专用残留清理仍未完成。
