# WASM 适配器执行与组合模块

当前外部音乐适配器与功能插件共用 `infrastructure/wasm_runtime.rs` 执行器，分别由各自管理器提供 Host 上下文。执行配置不再按调用类型、音乐平台、源码语言或包名区分。

## 执行限制（2026-11-03）

用户决定移除执行器的资源配额。普通功能插件与外部音乐适配器共用同一配置：不再限制 Component 文件大小、Store 线性内存总量、memory 数量、instances／tables／table 元素、fuel、实例化／初始化／每次 call 期限，以及 JSON 参数／响应大小。旧的分角色 `Budget`、`MemoryLimits` 与 `StoreLimits` 代码已删除。

仍保留的只有让出调度：Engine 开启 epoch interruption，每 10 毫秒递增 epoch，Store 使用 `epoch_deadline_async_yield_and_update(1)`，使 guest 计算周期性回到异步执行器。它不计数、不拒绝任何工作；没有它，一个死循环会永久占住调用线程。epoch 线程只持有 Engine 弱引用，最后一个实例释放后退出。

以下项目不属于本次移除范围：

- 并发与准入：编译进程级最多 2 个阻塞任务；每个外部适配器查询 4、播放解析 2；登录挑战最多 4 个、存活 180 秒并占用查询额度；每个功能插件最多 16 个待处理请求；最多同时加载 4 个 WASM 插件。
- 业务期限：单曲、业务／播放解析与登录等待仍由管理器绑定，`RequestContext` 负责取消；运行时不再有独立的强制中断。
- Host 能力：目标主机、IP、端口和 URL 凭证不限；HTTP 与 WebSocket 分别授权，HTTP 等待期限由调用方设置，省略时不设默认期限；WASI random 沿用 `WasiCtxBuilder` 的 64KiB 单次参数。
- 安装与卸载：插件安装包仍限 1024 文件、64MiB 解压总量，UI 入口与资源单文件 8MiB；插件卸载仍以 1 秒包装 `shutdown`。

历史：2026-10-15 先取消音乐适配器 fuel；2026-11-03 取消其余执行配额。

代价：单个 guest 现在可以分配到整机可用内存，也可能长时间占用执行；一次调用可能永不返回，只能通过停用插件、取消账号或结束进程恢复。trap、非法 JSON 与 faulted 标记仍会隔离受影响的 Store，后续请求从干净实例开始。

## Rust 密码组件

`packages/wasm-crypto` 用 RustCrypto 实现通用密码原语，作为适配器的内部依赖，构建时通过 WIT 组合。不增加宿主密码方法或任何平台专用签名操作，JS 协议代码仍负责调用顺序、认证字段与平台规则。算法、输入限制和构建方式见 [密码模块说明](../packages/wasm-crypto/README.md)。

组合后的 Component 对宿主继续提供现有 initialize/shutdown/call，内部密码接口不再是外部导入。语言运行时及所有子模块共享同一 Store 与执行路径，不再计入任何配额。安全随机数、HTTP、计时器与 WebSocket 仍需要分别验证并按受控通用能力提供，密码模块不代表这些能力已经完成。

这一阶段未注册可用 QQ 来源，未接入真实账号、扫码或完整音乐协议；不能把密码模块测试描述为第二适配器已经可用。

## 验证范围

Windows x64、Rust 1.95.0、Wasmtime 46.0.1、ComponentizeJS 0.23.0、jco 1.37.0、wac 0.12.0。公开固定向量聚合探测在仓库共享执行器连续三次通过；探测产物12,151,969字节，debug加载含编译约204秒，调用约4.09／2.98／2.90毫秒。重现脚本位于密码模块，源码归档后重新构建的fixture为12,159,174字节，外部导入检查及快速Wasm对照通过。此处不把debug编译时间作为Release实例化成本，也没有测量实际线性内存峰值或完整协议性能。

宿主库回归175项通过、4项既有测试忽略，覆盖既有外部适配器、账号、缓存、播放与插件。执行器测试验证 5000 万次指令与 80MiB 分配均不再被计量、fuel 插桩保持关闭，以及 trap 与非法 JSON 不污染后续实例。Rust密码模块3项测试和1项文档测试通过，严格Clippy通过。宿主Clippy仍有歌词与播放核心的既有警告，本轮不修改它们。格式检查通过。

未执行macOS/Linux原生构建、真实音频播放、真实平台账号、WebView释放或Release性能验收。共享HTTP、安全随机数、时钟、计时器、WebSocket、完整协议接入及平台专用残留清理仍未完成。
