# Nons 开放 API 设计

桌面端提供无需身份验证的进程内 HTTP／WebSocket 服务，外部应用通过 HTTP 查询与控制，通过 WebSocket 订阅事件。当前接口与使用方式见 [桌面开放 API](open-api.md)。

## 服务与设置

“设置 → 网络与服务”提供开关、端口、局域网访问、运行状态、连接数、地址复制和文档入口。默认关闭，端口 46321，默认仅监听本机；启用局域网后监听 IPv4 网卡。设置保存在既有 SQLite settings，服务独立于主 WebView，随应用退出停止。Android 不提供该服务。

## 能力边界

播放控制进入现有播放 Actor，有界排队并返回核心处理结果；音源解析与实际播放结果由状态与事件表达。HTTP 提供播放状态、只读队列、播放控制、封面和 TTML；WS 推送快照、播放、队列、进度与歌词失效事件。随机、循环和队列跳转携带队列版本，拒绝过期版本。歌曲使用不透明标识，公开响应不包含本地路径、上游音频地址或请求头。

## 歌词

以一份 AMLL 兼容 TTML 承载原文、已有翻译与音译。QRC、YRC、LRC 经成熟解析器与 TTML 生成器转换，保留来源的逐词或逐行精度；TTML 原文在无需合并或 CUE 变换时保留。来源选择、本地歌词、手动纠错、缓存和失效复用现有歌词服务。

歌词正文保持媒体时间轴，响应头独立交付全局与单曲偏移之和，允许负值。桌面全局偏移保存在共享原生设置，窗口经事件同步；首次初始化从旧 WebView 偏好迁移。正文 ETag 不随偏移改变。

转换使用两个并发任务，输入输出有大小限制；拒绝 DOCTYPE 与过深 XML。请求合并只在途共享，不新增派生歌词磁盘缓存。来源、曲目或缓存代次变化后拒绝过期结果。

## 事件与资源约束

事件订阅先注册再读取快照，忽略快照切点以前的事件。同批次可以共享序号，进度可合并；慢客户端失步后重新连接同步。HTTP 请求与 WS 连接数有界，发送和关闭有期限，客户端背压不阻塞播放 Actor。

服务无账号、令牌、配对或客户端权限管理。HTTP 允许跨源访问，校验监听地址对应的 Host；封面仅由曲目标识取得，沿用既有封面缓存。
