# 架构决策与有效约定

这里保存架构决策及其有效范围。项目整体范围见 [项目约束](../architecture.md)，接口细节见对应开发文档，依赖版本与验证记录以实际配置和 [实现记录](../implementation.md) 为准。

| 决策                                                                     | 保留的约定                                                                                                      |
| ------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------- |
| [0001：播放核心边界](0001-playback-boundary.md)                          | 本地与在线共用独立播放核心；网易云直连的阶段性约定由 0006 替代。                                                |
| [0002：缓存与本地目录](0002-runtime-and-ttml-cache.md)                   | 运行时查询有界并统一失效；磁盘资源缓存仅保存 TTML；目录扫描按来源对账，保留原始文件。                           |
| [0003：插件运行与前端信任边界](0003-runtime-plugins.md)                  | Component Model 后端受限执行；React 前端共用主 WebView，必须信任；插件复用独立播放核心。                        |
| [0004：配置、页面与文件权限](0004-plugin-configuration.md)               | 配置保存与呈现独立；默认目录授权，可显式确认任意文件权限；卸载不删除外部文件。                                  |
| [0005：宿主与插件职责](0005-plugin-capability-boundary.md)               | 宿主提供受控能力；插件实现第三方业务；暂不建立多来源框架的限制由 0006 替代。                                    |
| [0006：统一音乐适配器](0006-music-provider-adapters.md)                  | 适配器属于插件但独立管理；适配器负责登录，账号管理器保存凭证；网易云随包提供、先内置后拆包。                    |
| [0007：当前来源与补充来源](0007-current-and-supplementary-sources.md)    | 来源与适配器平行独立；能力范围与使用角色分开；宿主协调补充搜索，曲目保留真实来源。                              |
| [0008：账号驱动来源与聚合搜索](0008-account-driven-source-and-search.md) | 登录／账号选择成功切换当前来源；搜索逐项标明来源；曲目平台与播放音源独立，局部失败不抹掉结果。                  |
| [0009：多语言 WASM 与通用 Host](0009-language-neutral-wasm-host.md)      | 外部适配器共用 Component 与能力契约；语言构建和平台协议归包，宿主按通用能力扩展；替代 0008 的 QQ 原生优先选型。 |

0006 已完成阶段一至五：统一契约、播放与业务路由、账号凭据迁移、受限外部 WASM 验证、默认网易云原生源码包拆分和独立设置管理。网易云源码包随宿主编译链接，第三方平台的完整权限与运行时安装尚未开放。它部分替代 0001 与 0005 的阶段性约定，其余约定继续有效。历史曲库／队列存储格式仍保留兼容，具体进展与验证范围见 ADR 与 [契约记录](../music-adapters.md)。后续改变决策时明确标注被替代的记录，避免并列保留互相矛盾的约定。

0009 确定后续外部适配器的共同运行方向和 Host 建设范围，补充 0003/0004/0005/0006，替代 0008 的 QQ 原生优先选型；通用 Host、外部账号、包安装和多语言验收尚未实现，不计入既有完成阶段。
