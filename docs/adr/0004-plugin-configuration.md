# 插件配置、编辑页面与文件权限分别声明

状态：已接受。

插件需要选择统一配置页面或自行呈现设置，也可能独立保存文件。因此配置管理、页面呈现和文件权限分别声明，避免自定义页面必须依赖宿主配置存储，或保存路径就自动获得文件访问权限。

配置管理器负责默认值、校验、持久化、修订冲突与通知。包内配置定义禁止远程或外部引用，字段键按字面量处理；保存具有原子性，旧修订不能覆盖新值。规则变化后的无效旧值保留，读取回退默认值并提供诊断，直到用户修复或重置。

统一配置在插件停用时仍可编辑；自定义页面需要加载插件，并使用设置对话框内的独立导航。需要重新加载的字段与加载时快照比较，宿主提示重载，插件按声明的生效方式消费配置。

持久数据目录与安装代码分离。默认文件访问限于专属数据目录或用户通过原生选择器授权的外部目录，使用根标识和相对路径。用户明确允许增加任意文件授权：插件可声明 `fileRoots: ["*"]` 和 `files:selected`，经敏感权限确认后通过 `root: "*"` 与绝对路径访问文件，受操作系统当前用户权限限制。此范围进入授权指纹，旧目录授权不能自动扩大；停用或卸载关闭句柄与文件系统根。前端信任边界遵循 [ADR 0003](0003-runtime-plugins.md)。

2026-10-14 补充：外部音乐适配器可复用配置与存储基础设施，但分区、授权和生命周期由 AdapterManager 绑定，范围见 [ADR 0009](0009-language-neutral-wasm-host.md)。平台凭据统一由 AccountManager 保存，登录敏感临时状态使用有界后端挑战；普通配置或设备状态存储不替代这两项。功能插件既有文件授权不自动赋给适配器或语言运行时。

卸载默认清理配置、键值存储和专属数据，用户可以选择保留；外部目录授权始终撤销，外部文件不删除。接口、编辑器、限额和示例见 [插件配置开发](../plugin-configuration.md)。
