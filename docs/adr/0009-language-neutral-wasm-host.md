# 多语言适配器共用 WASM 契约，宿主按能力扩展

状态：已接受的架构方向；通用 Host、外部账号 ABI、安装与多语言验收尚未实现。日期：2026-10-14。本决策补充 ADR 0003、0004、0005、0006，替代 ADR 0008 中 QQ 优先采用原生 Rust 包的后续接入方向；现有网易云原生包保持运行，迁入 WASM 另行验证。

## 背景与决定

多来源接入需要复用不同语言的成熟实现，但按项目或语言增加宿主加载器、进程桥和平台接口会持续扩大维护面。后续外部适配器统一交付符合版本化契约的 WebAssembly Component；宿主依据声明的导入、导出及授权能力运行它，不依据源码语言或上游项目名称选择执行路径。

语言工具链负责将源码、必要的语言运行时和依赖组成合格 Component。语言 SDK 只提供同一契约的绑定和构建辅助；JS/TS 的解释器或标准库替代、Go 的目标与依赖适配均留在构建方案和适配器内。宿主不增加 Quaver、QQ、Go 或 Node 专用服务桥，也不承担完整 Node/Electron 环境兼容。能够构建 WASM 不等于具备宿主未提供的系统能力；尚未通过契约和预算验证的语言不标为已支持。

各语言适配器 → 统一 Component 导出 → AdapterManager → 通用 Host 导入，是唯一外部适配器接入方向。业务仍使用统一来源、账号、曲目、分页和播放资源语义；平台签名、认证字段、会员判断、音质候选与解密算法归适配器。融合 QQ 的 TS/JS 源码或参考 Quaver 只影响适配器内部实现，不扩大宿主的平台职责。

上述平台职责指音乐适配器业务。独立歌词服务按用户明确设计继续保留在 `lyrics`，其平台请求、评分与 QRC 解密不属于本 ADR 的迁移范围，也不作为适配器架构残留要求整改。

## 通用 Host 的范围

Host 是宿主向 Component 提供的受控外部能力。优先复用现有基础设施，按真实需求逐项开放；能力名称和方法与语言、平台无关。以下为需要补齐的设计范围，不是已可调用的 SDK 清单，具体方法、额度与版本在实现前落入契约文档。

当前功能插件和外部适配器已共用 `infrastructure/wasm_runtime.rs` 的执行器与 Component transport。功能插件通过自己的 Context 绑定 Host，外部适配器仍绑定 `NoCapabilities`。`plugins/http.rs` 已有 GET/HEAD/POST、有限头部、Cookie、Set-Cookie、超时和停用取消；后续应将其通用执行与校验部分提取到共享基础设施，由两类调用上下文绑定，共用实现和连接池，按身份选择预算。不是另建适配器 HTTP 栈，也不是将整个 PluginManager/Context 交给适配器；独立注册表与账号范围继续遵循 ADR 0006。

| 能力           | 需要补齐的内容                                                                         | 归属与约束                                                                                                                                        |
| -------------- | -------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| HTTP           | GET/HEAD/POST、有限头部、请求正文、文本与二进制响应、状态与必要 Set-Cookie 数据        | 宿主负责网络与 TLS；适配器拼装协议和管理 Cookie。按包授权校验每个目标与跳转，限制时间、并发、头部、正文及解压后大小；普通查询与播放解析分开预算。 |
| 账号调用与凭据 | 外部登录、轮询、资料、刷新、失效通知；读取当前调用范围的不透明凭据，交付登录或刷新结果 | 复用 AccountManager；宿主从调用上下文绑定来源、账号、挑战及代次，不接受 guest 自报身份。凭据提交经宿主复核与持久化，普通业务不能任意改选账号。    |

HTTP 与账号权限相互独立；声明音乐业务能力不自动获得网络或凭据权限。复用功能插件的连接池、校验器和存储机制，不复用其实例身份、注册表或现有小响应预算。适配器需要原始凭据时仍须受信任，WASM 的执行隔离不保证同时获网络授权的代码不会外发凭据。

所有适配器的已登录账号与持久凭据统一进入 AccountManager，新增来源通过统一账号契约保存、选择、刷新和删除；适配器不另建账号文件或私有账号库。已有网易云旧凭据迁移需隔离为历史兼容责任，并如实报告未完成的通用化部分。

### HTTP 的平台特有校验需求

共享 HTTP 应允许适配器构造所需方法、查询参数、合法自定义头和有界二进制正文，读取状态、必要响应头/Set-Cookie 与有界原始响应字节；保留正确的字节内容供 guest 计算签名或校验，不能强制所有协议只使用 UTF-8 文本和固定的少量业务头。具体扩展的方法集合、头部限制及二进制编码在实现前写入契约。

校验分两层：宿主始终执行域名/连接目标授权、TLS 默认验证、HTTP 语法、危险头部与资源预算；适配器执行平台签名、摘要、时间戳、Cookie 语义及响应合法性等特殊校验。自定义头不授予改写底层连接主机或绕过网络授权的能力。若实际需求包含证书/公钥固定校验，作为通用可声明策略另行设计和验证，不增加平台专用方法，也不通过关闭 TLS 验证满足需求。

当前 `plugins/http.rs` 的方法、固定请求头白名单、文本正文与 8KiB 响应不足以覆盖这些目标。先提取共享请求实现，再扩展有限参数和返回信息，按调用身份绑定额度；此处记录的是设计，尚未暴露新接口。

默认网络范围使用精确域名或受限子域声明，校验 DNS 解析与实际连接目标，阻止借重定向、私网或回环地址越过授权。扩大的范围按敏感权限重新授权；TLS、代理和连接池策略由宿主统一提供，平台要求的 HTTP 字段由适配器在已授权范围内提交。

## 执行、传输与版本

先在现有版本化 Component transport 上补通用 Host 和外部账号路由，复用取消、fuel、内存及独立播放预算。初始化、Host 等待、重试与返回检查都计入同一调用期限；停用、撤权和代次变化取消在途工作并拒绝旧结果。guest 在平台写请求发出后被取消，不保证远端撤销成功，写操作不得由宿主自动重放。

保留按请求新建 Store 的初始隔离方式，将跨调用状态显式交给 Host。若语言运行时的实例化开销或长连接需求使该方式不适用，先测量并另行记录通用生命周期变更，不为某语言绕开取消、账号隔离与预算。

WIT 导入/导出版本、音乐业务契约版本、Host 能力及其额度分别校验；加载前检查必需能力，未知必需导入明确拒绝，缺少可选能力返回不支持。兼容路径沿用当前 `initialize/shutdown/call` 与 `music.*` 语义，现有 fixture 的拒绝 Host 模式继续用于回归，不通过悄悄放宽权限升级旧包。

当前 JSON transport 的单次 64KiB 与音乐业务的 2MiB 结果上限不是同一个预算。二进制的编码膨胀、64KiB 凭据及平台响应必须计入实际传输大小；不能直接把领域上限当作 IPC 上限。先通过小页与有界分块/句柄表达所需数据；确需类型化二进制或新 WIT world 时版本化演进，并验证所有已支持语言，不整体放大普通插件预算。具体传输选择与数值由实现验证确定。

不开放通用进程启动、任意文件系统或裸套接字。必要的标准 WASI 接口按所选子集、同一权限和预算接入，不因某语言编译产物要求导入就开放完整 WASI。

## 播放与可选能力

首阶段使用已有播放资源描述与宿主音频管线，补受控后端对解析出的 URL、请求头、域名范围、重定向、有效期及试听范围的消费；普通页面和功能插件不取得这些敏感数据。当前 URI-only 管线拒绝非空头部，含头资源支持是待实现项。二进制 HTTP 用于有限协议数据，不把整首音频通过 JSON Host 调用搬入 guest。

加密音频若需要持续 guest 解密，先设计通用的分块变换、绝对偏移/seek、背压、资源撤销与解密状态预算，并在音频线程之外验证；不能把 QMC 算法放进宿主或把取到密文地址标为可播放。该能力不作为普通明文平台接入的前提，未实现时相关资源明确不可用。解码、队列、预加载、播放缓存和系统媒体控制继续由宿主负责。

移动端推送扫码若需要长连接，按可选通用 WebSocket 能力评估连接数、帧/消息大小、空闲期限、取消和实例隔离；MQTT 协议留在适配器。二维码 HTTP 轮询可先接入，微信/手机推送、短信或浏览器授权按平台实际能力与通用登录展示契约另补，不能用平台专用 Host 方法代替。

## 安装与交付

AdapterManager 独立负责 Component 包安装和生命周期；可复用普通插件的解包、路径校验和授权基础设施。包描述包含稳定来源、入口、契约版本、必需/可选 Host 能力、网络范围和配置定义，宿主验证其与实际导入及 descriptor 一致。旧包扩大权限重新授权；覆盖安装前校验兼容性，失败保留可运行版本，重载推进实例代次。平台/语言运行时随适配器包交付并计入同一包大小、内存和执行预算。

安装是交付能力，不是协议实现的前提；先用显式后端加载验收通用 Host，再开放安装。下载管理、普通功能插件前端和历史队列迁移不因本 ADR 一并改造。现有网易云原生路径不授予新外部适配器绕过统一运行接口的例外。

## 实施顺序与完成条件

1. **契约和最小 Host**：确定导入/导出、字节预算及权限描述；提取并扩展已有 HTTP，接入适配器 Context，补时间/随机和稳定错误，构建受控网络 fixture。必须通过未授权目标、跳转越界、超大/慢响应、取消与查询满载不占用播放预算的检查；既有功能插件 HTTP 权限和预算保持有效。
2. **外部账号和业务**：补账号 ABI、挑战状态及必要配置/设备状态，接入真实搜索、详情、登录、刷新、曲库和写入。必须验证来源/账号越权、旧挑战取消、刷新竞争、凭据保存失败、旧结果拒绝及写后缓存失效；不靠 fixture 宣称平台可用。
3. **播放和交付**：验证实际音质、禁止降级、试听、过期重解析、带头资源与混合队列，再开放包安装/升级/撤权。必须验证 WebView 释放后继续服务、停用/重载和正常退出后的资源清理；加密流与长连接只在独立验收通过后声明支持。
4. **多语言共用验收**：至少两种语言产物运行相同 fixture 与音乐契约测试，宿主没有按语言/平台分支；分别记录工具链、构建步骤和依赖限制。Windows 优先，macOS/Linux 编译与基本播放持续验收；Android 和具体语言支持范围以实际结果为准。

各阶段记录冷启动、实例化、缓存命中首声与后台播放的环境、场景、延迟统计和内存；语言运行时也计入应用成本。共用接口是已接受方向，不等于所有语言成本相同，也不承诺任何上游项目可原样迁入。新 Host 能力须同时更新契约、授权展示、生命周期和测试，保留现有网易云与功能插件回归。

## 取舍与依据

接受一次通用 Host 与语言构建绑定的建设成本，以减少每接入一个项目就修改宿主的长期成本。平台源码优先复用成熟实现，但需要满足共同执行预算；未通过验证的 Node/Go 服务不会作为捷径进入发布路径。现有受限 fixture 和网易云原生包仍按各自实现记录描述。

Component 的 world 用导入描述所需外部能力、用导出描述提供的能力，语言无关不表示自动获得操作系统环境。技术依据见 [Component Model 的 WIT](https://component-model.bytecodealliance.org/design/wit.html) 与 [worlds](https://component-model.bytecodealliance.org/design/worlds.html)；本轮经 Context7 核对，未据此承诺具体语言工具链可用。当前源码与限制见 [适配器契约记录](../music-adapters.md#阶段四修改记录与注意事项2026-10-10)，宿主现有平台残留及 HTTP 复用差距见同文的“宿主平台职责审查”；资源与失效继续遵循 [缓存约定](../cache-and-local.md)。
