# 所有在线音乐来源通过统一适配器接入

状态：已接受；阶段一至五已完成（契约、内置接线、业务与账号迁移、受限外部执行验证、默认网易云原生源码包拆分与设置管理）。桌面端已开放外部包的导入、权限确认、升级回滚和卸载；完整 WASM Host 能力、应用商店和 Android 导入仍按 ADR 0009 的受控范围推进。日期：2026-10-30。

本决策替代 [ADR 0001](0001-playback-boundary.md) 中允许网易云直接耦合、等待启动多来源框架化的阶段性约定，以及 [ADR 0005](0005-plugin-capability-boundary.md) 中暂不建立多来源框架的限制；独立播放核心、受控宿主能力和前端信任边界继续有效。当前代码和已开放接口仍以 [插件开发与使用](../plugins.md) 与 [实现记录](../implementation.md) 为准，本文不表示迁移已经完成。

多来源使用角色与补充业务由 [ADR 0007](0007-current-and-supplementary-sources.md) 补充：当前来源与补充来源是用户配置中的角色，适配器保持平行独立，能力范围与角色分开。

2026-10-14 补充：后续外部适配器统一采用多语言共用的 WASM Component 与通用 Host，职责、所需能力和验收见 [ADR 0009](0009-language-neutral-wasm-host.md)。本文“运行位置可以不同”保留现有网易云原生包及其历史阶段，不作为新增平台/语言专用进程桥的依据。阶段四受限执行和阶段五原生拆包的已实现范围保持不变，完整外部能力仍待建设。

## 背景与决定

项目进入多流媒体来源框架化阶段。网易云原生支持是过渡实现，最终与其他在线音乐平台一样作为音乐适配器接入。网易云继续随安装包提供，先在宿主内实现统一适配器接口，后续迁为独立适配器包；随包分发只影响安装与初始化，不赋予独立的业务调用路径。

宿主页面、功能插件和播放资源解析通过统一音乐服务与适配器管理器访问来源。迁移完成后，宿主通用业务不再直接依赖网易云客户端、平台响应或专用 ID 类型。内置和外部适配器遵守相同的公开契约、能力声明、错误、取消、缓存与生命周期规则；运行位置可以不同，契约测试共用。

## 管理归属

音乐适配器是插件的一种，提供音乐来源能力；功能插件提供工具、业务流程或界面扩展。新增独立的适配器管理器（`AdapterManager`），负责适配器发现、安装、加载、启停、版本兼容、能力注册和故障处理，并提供独立管理入口。现有插件管理器（`PluginManager`）继续管理功能插件，适配器不进入其运行注册表，也不由它加载后再转交。网易云从内置阶段起也由适配器管理器管理。

两类管理器可复用包校验、授权、配置、存储和后端执行等基础设施，但各自持有注册表、运行状态和生命周期。基础设施复用不等于统一管理。账号管理器与适配器管理器分别管理账号数据和适配器运行状态，通过绑定来源与账号的上下文协作。

## 职责与接口

音乐适配器提供平台能力供宿主调用，功能插件调用宿主能力实现工具或界面扩展，两类契约分别定义。灵动岛、下载和转换工具不因引入适配器而接管播放核心。

宿主负责统一音乐界面、查询调度、混合队列、音频读取与解码、缓冲和无缝预加载、输出设备、系统媒体控制、缓存预算及受控系统能力。适配器负责平台协议、登录协议、响应转换、平台业务规则和播放资源解析。平台专有能力通过可选扩展表达，不将其加入所有来源的必选接口。

基础契约包含来源描述、曲目读取和播放资源解析。搜索、内容浏览、账号、用户曲库、收藏与歌单写入、推荐、私人 FM、歌词和下载按能力组声明，按实际需求逐步实现。宿主同时区分适配器支持的能力与当前账号、曲目实际允许的操作，提供不可用原因，避免把试听资源当作完整播放资源。

公共契约遵循以下语义：

- 曲目、歌单、专辑和艺术家引用包含稳定来源标识与不透明字符串 ID；账号相关操作另带会话上下文。相同平台 ID、相同歌名或歌词匹配不改变曲目来源，跨平台匹配另存关联。
- 分页使用不透明游标，由适配器转换为平台页码、offset 或 token。结果和请求均设数量、大小与时间上限。
- 播放资源描述包含实际音质、试听限制、有效期与访问方式。宿主校验后建立受控资源句柄，带凭据的 URL 和请求头只在内部消费，不交付普通插件、写入日志或持久化队列。过期资源重新解析，预加载结果同时检查播放、账号和适配器代次。
- 账号获取、凭证格式和平台登录协议由适配器定义，持久凭证由账号管理器统一保存，具体职责和信任边界见下节。普通功能插件通过业务接口查询、收藏和播放；现有显式授权的 `account:credentials` 作为敏感兼容能力保留，不作为通用音乐接口的前提。
- 宿主统一控制缓存容量、淘汰、请求合并和失效，适配器提供缓存建议及写操作影响范围。缓存键区分来源、账号范围、操作和参数；账号切换及写操作不能复用旧结果。
- 错误区分未登录、资源不存在、权限不足、地区限制、限流、网络失败和能力不支持；平台原始信息仅作为经过敏感数据过滤的诊断补充。

## 账号管理与凭证边界

适配器完整负责平台特有的账号获取方式和登录流程，包括二维码、密码、浏览器授权等实际采用的方式，以及凭证解析、校验、刷新和失效判断。账号管理器不规定平台的登录步骤、成功条件或凭证字段，也不实现平台刷新协议。宿主可以提供登录界面容器，内容和交互由适配器决定。

账号管理器统一管理账号记录、当前账号选择、凭证持久化和状态通知，按来源与账号隔离。凭证是适配器定义的不透明数据，不预设为 Cookie、Token 或固定结构。适配器完成登录后交付账号信息与凭证；运行时通过绑定来源、账号和加载实例的接口获取必要凭证，完成刷新后更新统一存储。账号管理器负责存储、访问控制与会话代次，适配器负责平台语义。

2026-10-14 明确：AccountManager 面向所有适配器，不是网易云账号管理器；每个平台的已登录账号均进入同一管理器，按来源与账号区分存储。当前 `netease-session` 分支是未隔离完的历史迁移责任，不能据此建立其他平台专用保存路径，也不能把存在该分支的实现报告为已经完全来源无关。隔离迁移时保留旧凭据和失败恢复。

停用适配器、切换账号、退出登录和删除保存账号是独立操作。停用撤销运行实例访问，不自动退出平台账号或删除持久凭证；退出当前账号仅取消该来源的当前选择，保留账号记录与持久凭证，不调用可能使保存凭证失效的平台退出接口；删除保存账号才由账号管理器清理对应凭证。两者均推进会话代次，使旧请求失效。

凭证统一持久化是适配器的强制契约：普通配置、业务存储、独立 secrets 分区、授权文件和浏览器存储均不得用于另存平台凭证。宿主执行最小权限，默认提供账号专用接口，仅按业务需要开放普通存储；文件访问和任意域名网络权限另行授权。功能插件默认不获得原始凭证，适配器也不能读取其他来源的账号凭证。持久凭证处理尽量留在后端，前端只消费登录展示和交互所需数据。

该契约不等于防恶意适配器沙箱。实现登录和刷新通常要求适配器接触原始凭证；同时具备原始凭证读取和通用写入或网络权限的代码，可能复制、编码后保存或外发凭证，宿主不能可靠依靠内容检测阻止。共享 WebView 的前端尤其不能靠 SDK 权限形成强隔离，继续遵循 ADR 0003 的信任要求。能够适用的请求可使用宿主凭证注入，但不强制所有平台使用同一种认证方式。

凭证访问依靠受控后端、来源与账号范围、实例代次和最小权限限制；接触原始凭证的适配器仍须受信任。账号管理器保证自己管理的存储与访问生命周期，不保证删除适配器私自复制或外发的数据，也不作为阻止凭证泄露的完整安全边界。

## 执行与生命周期

账号处理和播放资源解析在独立于前端页面的后端执行，WebView 隐藏、释放或插件页面卸载不影响来源继续服务。沿用 [ADR 0003](0003-runtime-plugins.md) 的受控后端方向；适配器不在音频线程执行。接入外部适配器前，重新核对 HTTP 响应上限、调用期限与并发预算，并为关键播放解析保留调度能力，避免普通查询阻塞首声或预加载。预算有界，性能结论需实测。

停用或卸载适配器时拒绝新请求，取消其未完成查询和预加载，撤销账号与资源访问能力。已交付播放核心且无需继续访问适配器的资源可以播放到结束；依赖已撤销访问能力的资源报告来源不可用。队列保留曲目引用并标记不可用，恢复来源后可重新解析，不直接删除用户队列。账号切换、重载后的旧结果不能覆盖新状态。

本地音乐复用统一曲目模型和通用查询体验，目录监听、索引及文件权限仍由宿主管理，无需套用在线登录协议。歌词来源独立于音频来源，继续由统一歌词服务安排来源顺序、匹配、缓存和回退。

## 取舍与迁移

继续扩展网易云专用接口成本较低，但会让第二个平台和后续网易云拆分承担重复迁移。直接将网易云整个实现搬进现有前端插件，则无法保证 WebView 释放后的账号与播放资源解析。采用统一契约、先内置后拆包的路线，增加接口和数据迁移成本，以换取宿主与平台实现可独立演进。

迁移按以下顺序推进，每阶段保持已有播放与本地音乐行为可用：

1. 确定统一标识、能力组、错误、会话与资源契约，划分独立适配器管理器、账号管理器与现有插件管理器的职责，以及历史曲目、队列和账号数据的迁移规则。
2. 在适配器管理器中注册内置网易云适配器，迁移单曲读取与播放资源解析；通用调用方只依赖统一接口。
3. 迁移搜索、内容详情、账号、用户曲库和写操作，功能插件逐步改用统一音乐客户端。现有 `netease.*` 仅保留为有迁移说明的兼容入口，不再承担新的通用能力。
4. 使用测试适配器覆盖非数字 ID、不同分页、缺少能力、账号切换、过期资源及停用，再接入一个外部适配器验证契约和运行预算。
5. 将网易云迁为默认随包提供的独立适配器，保持来源标识、已有数据及宿主调用契约稳定；完成后移除迁移期直连路径。

阶段一已确定内部方法名、DTO、契约版本和初始数据上限，见下节；外部 ABI 与运行预算仍在对应接线阶段确定。本决策不要求一次开放全部能力，也不承诺所有平台具有相同功能。验收覆盖适配器与功能插件管理隔离、不同登录流程、不透明凭证存储及越权拒绝、停用不删除账号、账号退出与删除的清理、适配器契约、混合队列、会话隔离、缓存失效、WebView 释放后的播放、停用与重载，以及既有播放和跨平台检查；受控接口测试通过不代表已能阻止恶意代码外发凭证。

## 阶段二完成记录（2026-10-10）

宿主启动时在独立 `AdapterManager` 注册内置 `netease`，由 `MusicService` 路由单曲读取和在线播放解析。播放 Actor 不再持有网易云客户端；当前播放与无缝预加载走同一统一资源接口。既有插件 `netease.get-song`／`music.get-song` 的单曲读取经统一接口执行，公开 DTO 和权限保持兼容。平台数字 ID 解析与旧 DTO 转换留在网易云兼容边界；本地 NCM 解码移到宿主 `local/playback_resource.rs`，歌词回退与混合队列保持原职责。

管理器验证契约版本、来源唯一性、曲目身份和大小，分别限制普通查询与播放解析并发，主动执行期限及旧上下文取消。受控资源登记表、资源有效期、账号／实例／播放代次在返回与播放交付时复核；无缝回调只消费有效的已准备资源，过期准备由后台重新解析。停用／恢复和内部重载推进实例代次，保留队列及账号；已经交付音频核心的独立 HTTP 资源继续播放。当前内置适配器以内部 API 管理，包发现、安装与独立管理界面待外部接线阶段实现。

登录仍复用既有系统 Cookie 存储，通过旧会话代次桥接隔离资源与歌曲缓存，不实现 AccountManager 或账号数据迁移。网易云固定版本客户端以保留上游实现的本地补丁限制响应体读取，音频继续复用既有 GStreamer HTTP 源、缓冲和有界播放命令队列。请求预算、资源限制、兼容接口及阶段三注意事项见 [音乐适配器契约与迁移记录](../music-adapters.md#阶段二修改记录与注意事项2026-10-10)；验证与平台限制见 [实现记录](../implementation.md)。阶段二没有开放外部 ABI 或新插件 SDK，也未迁移搜索、账号、详情与写操作；不将这些后续能力计入完成范围。

## 阶段三完成记录（2026-10-10）

搜索、建议、歌单／专辑／艺术家详情及曲目、用户曲库、历史、收藏、推荐／私人 FM 和歌单写操作已改由 `MusicService → AdapterManager → MusicAdapter` 执行。内置网易云声明实际实现的八个可选能力组；平台客户端与数字 ID 转换留在适配器及明确的兼容边界。统一业务请求、响应、来源描述和 TypeScript DTO 已开放，宿主使用 `musicClient`，功能插件使用 `useMusicSource`／受控 `music.*` 能力；内置灵动岛后端已迁移单曲读取。`netease.*` 与现有页面的旧 IPC/DTO 仅作迁移兼容入口，不再承载新的通用能力。

独立 AccountManager 接入系统凭据库与 SQLite 公开账号索引，按来源／账号保存不透明凭据，支持保存账号、选择和删除。网易云适配器确认旧 Cookie 的真实账号后，按“写入并验证新凭据 → 提交公开记录与完成标志 → 删除旧条目”的顺序迁移；失败保留可恢复状态，已有较新目标不覆盖。退出先撤销本地会话并记录清理，再执行适配器准备的远端退出；本地与远端结果分别报告。受控凭据访问绑定来源、账号和实例，停用／重载／刷新使旧访问失效，停用不删除账号。

业务调用验证能力、账号、引用来源、数量和响应大小；不透明游标绑定查询、账号、实例及写入代次。新增查询复用既有缓存，缓存命中、请求返回和写后失效复核代次；后台账号通知同步已有页面，旧响应不能覆盖新账号。普通业务与播放解析分别保留有界并发，系统凭据 I/O 进入有界阻塞任务。

修改清单、接口迁移方法、预算与注意事项见 [阶段三记录](../music-adapters.md#阶段三修改记录与注意事项2026-10-10)，验证见 [实现记录](../implementation.md#统一音乐适配器adr-0006-阶段三2026-10-10)。本阶段没有迁移历史曲库／队列存储格式，没有开放外部适配器 ABI 或安装管理界面；现有登录展示契约覆盖内置二维码流程，不宣称支持所有外部平台登录方式。外部运行边界、不同登录流程、真实第二来源及网易云拆包继续在阶段四、五完成。

## 阶段四完成记录（2026-10-10）

独立构建的 `plugins/music-fixture/backend` WASM Component 通过 `music/external.rs` 转为 `MusicAdapter`，由独立 AdapterManager 注册并执行；不使用 PluginManager 的注册、授权或贡献生命周期。来源 `fixture-radio` 使用 Unicode／非数字曲目 ID 和真正的两页 continuation token，覆盖能力缺失、账号代次切换、错误来源响应、过期／试听／带头资源拒绝，以及停用、恢复和重载后的资源失效。既有测试适配器与 AccountManager 回归继续验证主动取消、期限、账号越权、保存记录保留和缓存作用域。

受限外部 ABI 复用 `nons:plugin@1.0.0` 的 Component transport，单独定义 `music.descriptor/read-track/business/resolve-playback` JSON 方法与响应封套；宿主在注册前校验描述符一致性与音乐契约版本。每次请求独立实例化 Store，共享已编译 Component；取消销毁 Store，防止旧执行或 guest 状态污染下一会话。查询 4、播放解析 2 的预算独立，线性内存、fuel、有效载荷及初始化／执行期限沿用受控 Wasmtime 基础设施。真实 WASM 回归覆盖耗尽 fuel、内存增长、trap、非法／超大响应、Host 能力拒绝和故障后新请求恢复。

阶段四完成的是测试来源与受限外部执行验证，不等于已开放通用平台包安装：验证来源不随包安装，也没有真实音乐平台的网络和登录实现。当前桥仅允许 Search／Browse 可选组，不提供任何 Host Capability、WASI、前端、账号凭据访问或持久 guest 状态。阶段五拆网易云前须补平台域名授权与受控 HTTP、AccountAccess 和登录／刷新／退出 ABI、账号展示及独立安装管理；仍需验证真实第二平台、macOS/Linux、WebView 释放后的外部真实播放和 Release 性能。契约及注意事项见 [阶段四记录](../music-adapters.md#阶段四修改记录与注意事项2026-10-10)，实际验收见 [实现记录](../implementation.md)。

## 阶段五完成记录与执行方式（2026-10-10）

网易云迁为独立 Rust 源码包 `adapters/netease`，默认随宿主编译链接，平台 SDK 与原有有界 HTTP 补丁同步移至包内 `vendor/ncm-api-rs`。共享契约提取到 `packages/music-adapter-sdk`，宿主只重新导出相同类型。网易云包不依赖宿主 crate、Tauri、AccountManager、SQLite 或 keyring；宿主不再直接依赖 ncm-api-rs，也不再包含平台搜索、登录、曲库、写入或资源解析实现。来源 `netease`、契约版本 1、已有账号/曲库/队列/本地歌词绑定以及兼容 IPC/DTO 保持稳定。

本阶段选择受信任原生库包，沿用 ADR 允许的不同执行位置和共同业务契约，保留成熟平台客户端、连接池及独立于 WebView 的后端执行。没有把网易云迁入阶段四仅支持 Search/Browse 的 WASM 桥，也没有自建平台协议或新增 API 服务。原生源码包的升级需重新构建应用；它不是可在运行时安装或替换的 WASM 包，不具有 Wasmtime 沙箱隔离。阶段四提出的 HTTP 授权、外部账号 ABI、不同登录展示与包安装仍是第三方平台 WASM 接入前的门槛；不计入本阶段已实现能力。

启动组装归入宿主 `music/bundled.rs`：由独立 AdapterManager 注册网易云，通过单来源 `ProviderAccounts` 桥访问 AccountManager。读取前后核对会话、账号和实例，桥不提供账号存储或跨来源访问。普通业务与播放的凭据读取继续保留 4/2 的有界阻塞预算；登录完成结果交回统一账号存储，系统凭据迁移/选择/退出仍由宿主管理。功能插件管理器及歌曲服务不持有网易云客户端，显式授权的旧凭据兼容能力实时通过账号管理器读取并复核实例。歌词服务沿用独立来源策略；旧 DTO 转换和只读探测保留明确兼容边界，通用播放服务不引用平台包。

设置新增带 Blocks 图标的“适配器设置”，支持查看来源与能力、启停、重新加载及刷新。启停保存为本机设置，默认启用网易云，启动恢复停用状态；写盘失败不改变运行状态。停用或重载推进代次，取消在途请求、使缓存和预加载失效，拒绝新的凭据/资源访问，保留账号及队列；已交付音频核心的独立资源可继续播放。这里的重载刷新管理器代次，原生库和连接池保持链接，不宣称卸载原生代码。

修改记录和限制见 [阶段五记录](../music-adapters.md#阶段五修改记录与注意事项2026-10-10)，验证结果见 [实现记录](../implementation.md#统一音乐适配器adr-0006-阶段五2026-10-10)。本阶段未迁移历史曲库/队列数据库格式、未接入真实第二平台，未实测 Release 性能或完成 macOS/Linux 与 WebView 释放后的实机播放验收。
