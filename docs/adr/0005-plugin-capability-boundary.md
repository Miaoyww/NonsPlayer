# 宿主提供受控能力，插件组合能力实现业务

状态：已接受；暂不建立多来源框架的阶段性限制由 [ADR 0006](0006-music-provider-adapters.md) 替代。下文网易云账号与接口描述保留现有实现背景；后续音乐适配器与功能插件的职责及迁移遵循 ADR 0006，其他权限与受控能力约定继续有效。

为避免插件的第三方业务规则进入通用运行环境，SDK 按通用系统能力与播放器领域能力划分。宿主代理受控操作，插件负责内容识别、第三方协议、业务流程及呈现策略。

通用能力包含剪贴板、HTTP、文件、存储、配置与事件；播放器领域能力复用既有歌曲查询、播放状态、队列操作与音乐界面组件，并明确音乐来源。网易云服务沿用宿主账号和缓存，不另建播放核心或提前抽象多来源框架。

Windows 功能插件可显式申请 `process:spawn` 启动并管理任意子进程，或申请 `window:manage` 创建声明的独立窗口。进程由宿主以 Job Object 接管，输入输出有界，停用或退出时终止进程树；被启动的原生程序拥有当前系统用户的文件与网络能力，不受插件文件与 HTTP 授权范围限制，启用确认须明确展示此边界。窗口由宿主绑定插件身份与加载代次管理，仅加载插件声明的本地 UI 入口，主 WebView 释放不关闭独立窗口。其他平台不开放这两项能力。接口与资源上限见插件开发文档。

每项能力统一检查插件身份、权限范围、加载代次、取消与资源预算。网络域名和外部目录由授权限定；`httpHosts` 可显式声明 `*` 访问任意 DNS 域名，启用确认按敏感权限强调其可发送数据到任意域名，并提示同时授权账户凭证时的 Cookie 泄露风险。由精确域名扩大到 `*` 需要重新授权，URL 协议、凭证、端口与主机类型校验继续生效；通用 HTTP 不携带宿主账号凭据，也不自动跳转。插件决定是否跟随跳转，宿主对下一次请求重新校验权限。剪贴板授权明确为文本读取，旧音乐链接权限不能自动升级为原文读取权限。

需要以当前网易云账号执行业务的插件可显式申请 `account:credentials`，宿主在启用确认中以敏感权限强调其能够读取登录 Cookie 并以用户身份请求服务。凭证按当前账号及代次实时读取，不进入查询缓存，不授予更改宿主会话的能力；新增权限使旧授权失效。通用 HTTP 仍不自动附带凭证，由已授权插件主动使用。下载插件直接复用此能力，登录与退出统一在宿主处理。

新增能力只覆盖已有需求。特定平台域名、链接格式与短链解析归入对应插件；扩展或迁移时同步公开类型、宿主实现、授权展示和生命周期约束，并验证未授权访问、范围越界及停用后的失效。

2026-10-14 补充：外部音乐适配器的 Host 按 [ADR 0009](0009-language-neutral-wasm-host.md) 扩展通用网络、账号范围、状态与执行能力，语言及第三方项目不决定宿主方法。签名、登录、Cookie 字段、会员规则和解密算法归适配器；共用基础设施不共用功能插件的身份、权限分区或注册表。原始凭据的受信任要求继续有效；新的能力范围不表示既有功能插件自动获得适配器权限。

本地音频容器解析属于宿主的音频格式支持，本地索引、播放与受控文件工具复用同一解析器。NCM 使用成熟 Rust 库，独立转换插件负责选择、批量调度和结果展示，宿主的 `files.decode-audio` 负责有界流式解码、标签写入与不覆盖发布。这样无需让播放依赖前端插件的挂载，也不在播放线程运行插件任务；不扩展为流媒体来源框架。工具导航通过页面贡献的 `category: "tool"` 分类，仅挂载当前页面。

运行与前端信任边界见 [ADR 0003](0003-runtime-plugins.md)，配置与文件授权见 [ADR 0004](0004-plugin-configuration.md)，当前接口见 [插件开发与使用](../plugins.md)。
