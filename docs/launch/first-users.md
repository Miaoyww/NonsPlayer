# NonsPlayer 首轮内容与试用招募

准备日期：2026-10-11。目标渠道：B站、小红书。本文是发布草稿与执行方案，尚未发布。

## 定位与目标

核心表达：**一个专注听歌的桌面播放器，把网易云音乐与本地音乐放进同一个界面。**

首轮面向使用 Windows、平时听网易云或有本地音乐收藏、在意播放器界面与歌词体验的人。用真实界面展示音乐库、歌词、悬浮播放栏和本地音乐；技术栈留在有人询问时解释。

建议首轮招募目标为 20 位实际安装的试用用户，获得至少 5 份包含使用场景的反馈。数字是本轮执行目标，不是现有用户量或增长预测。

语气使用开发者第一人称，具体、自然：为什么做、现在能做什么、希望用户帮忙体验什么。功能介绍依据当前实现；避免把“极低内存”“全平台成熟可用”“多平台曲库聚合”作为已验证卖点。首轮说明 Windows 优先，macOS/Linux 尚待实机验证。在线歌曲的可播放范围、音质取决于来源与账号权限。

## 下载入口的当前状态

2026-10-11 核对公开 [GitHub Releases](https://github.com/Miaoyww/Nons/releases)，尚无公开版本。正式试用招募前，准备一个 Windows 安装包，并完成干净环境安装、启动、账号登录、本地与在线播放的实际检查；发布流程见 [release.md](../release.md)。

安装包未发布时采用下方“预告版”结尾。发布后改用“试用版”结尾，补上真实版本号与对应 Release 链接；不要提前写“现在可以下载”。

## 素材与首次发布

先录一份约一分钟的桌面素材，从中剪出 B站短视频，并截取小红书图片。全部使用当前版本真实界面；清理画面中的私人账号信息、通知和本地文件路径。演示音频选择自制或已明确允许使用的素材。

录制顺序：音乐库 → 歌单播放 → 本地音乐 → 歌词 → 悬浮播放栏。截图分别保留完整原图，视频适配时重新裁切；图文上的字不要覆盖歌曲、按钮或歌词。首轮不需要新官网或投放预算。

建议节奏：

1. 素材准备完成后发布首条预告；如果安装包已完成实机检查，则直接发布试用招募。
2. 整理第一轮评论中的真实疑问，补充安装与使用说明。
3. 有安装包后发布试用内容，明确版本与反馈入口。
4. 第一批反馈带来实际修复后，发布“根据试用反馈改了什么”，展示具体前后变化。

这是一轮内容序列，不是已创建的定时任务。

## 反馈与判断

首轮以评论和 [GitHub Issues](https://github.com/Miaoyww/Nons/issues) 接收反馈。遇到可复现问题，引导用户补充版本、Windows 版本、操作步骤、预期与实际结果。暂时不要求用户注册新的反馈工具。

评论回复草稿：

> 谢谢愿意试用。最想知道你实际听歌时遇到了什么：可以说下版本、操作步骤和哪里不顺手；GitHub Issue 也可以，我会按问题整理修复。

人工记录一张简单表：日期、渠道、内容链接、是否成功安装、使用场景、问题、是否解决、是否愿意继续使用。不记录无关的个人信息。

衡量时区分曝光、安装与持续使用。观看和点赞可从各自平台后台查看；没有下载归因或使用统计时，不推算安装转化率、日活或留存。GitHub 附件下载量也不能当作独立安装用户数。

优先关注三类回答：安装是否成功；能否顺利听完歌；使用几天后是否愿意继续打开。先处理阻断安装和播放的问题，再决定下一轮内容与功能改动。
