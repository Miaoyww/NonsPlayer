# 缓存与本地音乐

修改资源获取、缓存设置或目录管理时阅读本文。这里定义复用边界；容量常量与已注册命令以对应实现文件为准。

## 便携版数据目录

Windows 便携包通过 EXE 同目录的 `portable.flag` 启用独立数据目录：配置、曲库和插件数据位于 `data/`，资源与 GStreamer 注册缓存位于 `data/cache/`，WebView（含展示预览）位于 `data/webview/`，临时 NCM 解码位于 `data/temp/`。账号与插件凭据使用 `data/credentials/` 内的文件，不访问系统凭据库；凭据不加密，移动目录时应妥善保管。目录不可写时明确失败，不回退到 AppData。安装版维持系统目录策略；便携版不自动读取或迁移安装版的数据。外部授权的音乐、下载文件继续位于用户选择的目录。缓存清理不删除账号凭据、设置和曲库。

## 插件资源与歌曲信息

插件配置默认值与用户覆盖值按修订号读取，不加入查询缓存；写入通知刷新相关配置，清理资源缓存不删除配置。独立数据目录为应用数据目录下的 `plugin-data/<id>`，文件 IO 在阻塞工作线程执行。停用关闭实例句柄，撤销授权关闭对应句柄；卸载默认保留配置、键值与专属数据，主动关闭保留选项后才清理。外部授权总会撤销，外部内容不删除。接口与限额见 [插件配置开发](plugin-configuration.md)。

插件 React SDK 仍通过 `nativeCall` 调用 scoped IPC，封面沿用 `useCoverSource`／`runtime_cover`。方法调用、权限检查、生命周期、存储与插件列表不加入查询缓存：每次必须验证当前加载代次，不能由缓存绕过禁用或权限判断。

`accounts.credential-read` 仅交付给显式授权 `account:credentials` 的活跃插件，按来源分块读取不透明凭据和账号／实例上下文，每块最多 4096 字节，不缓存、不写插件存储。下载插件每次解析资源前读取，并在发布前核对账号代次；切换账号或退出后旧下载结果不得发布。`files.resolve/play/open-directory` 每次核对根目录授权与路径；已下载文件继续独立于播放缓存，列表复用宿主组件与封面缓存，不自动添加曲库目录。

插件设置的 ZIP 拖入与文件选择共用 `plugin_install`，安装后沿用 `plugins-changed` 更新列表；搜索仅筛选当前已安装列表。`plugin_open_folder` 由宿主直接打开插件管理器的安装目录，不接受前端路径参数，不加入查询缓存。

WASM 无法调用 WebUI 的 `nativeCall`，因此 `plugins/music.rs` 的 `SongService` 为 `music.read-track` 提供共享的 Rust 运行时缓存，以完整 EntityRef 为键，底层经统一 MusicService／AdapterManager 路由到对应适配器并复用各自连接池；旧数字歌曲方法已移除。成功结果 TTL 10 分钟，不延长命中 TTL；128 条上限，每个公开 DTO 最多 64KiB，有效载荷估算上限约 8MiB。查询串行合并重复请求，失败不缓存、不持久化，单次网络预算 3 秒。

通用剪贴板读取与变化事件是实时能力，不加入查询缓存；待处理原文有 16KiB 上限，消费或停止监听后清理，不持久化。通用 HTTP 请求用于插件自己决定的资源获取，不进入宿主网易云查询缓存，也不携带宿主账号凭据；响应不缓存。插件需要缓存业务资源时使用独立存储或文件能力，自己管理容量、过期与失效。宿主只复用有界连接池；接口预算见 [插件接口](plugins.md)。

单曲缓存命中和写回同时检查适配器启用、实例代次与旧会话桥接代次，停用或重载不能命中旧条目；扫码登录成功、会话失效和退出推进账号代次并清空该缓存；旧请求不得写回。缓存只保存公开歌曲元数据，不提供 Cookie、临时播放地址或本地文件路径。插件专属键值存储位于 `plugins.sqlite3`，不属于可清理资源缓存；关闭插件保留数据；卸载默认保留分区，用户主动关闭保留选项后才删除。动态 UI／资产使用加载代次 URL 和 no-store，禁用后拒绝新资源请求；浏览器已经加载的 ESM 模块记录不能主动回收。

## 音乐适配器管理

### WASM 编译结果缓存

外部音乐适配器与功能插件共用 Wasmtime 编译结果缓存，位于应用缓存目录的 `wasm-compiled-v1/`；便携版使用 `data/cache/wasm-compiled-v1/`。缓存只包含编译后的代码，不保存 Store、账号、凭据、权限或运行中的 guest 状态。缓存键与兼容性检查由 Wasmtime 处理，源码、引擎版本、目标及编译配置变化后重新编译；损坏条目回退编译，缓存目录不可用时记录警告并继续无缓存加载。每次加载仍验证描述符，每次调用仍新建 Store 并执行原有权限、取消、代次和时间预算检查。

容量采用 Wasmtime 原生 **512 MiB 软限制**及后台回收，可能暂时超过该值；宿主不另行扫描或强制裁剪。它属于运行时基础设施缓存，不受 TTML 缓存目录、开关或清理控制；删除该编译缓存目录后，下次加载自动重建。编译共享两个 Rayon 工作线程，同一时间编译一个组件；编译在阻塞工作任务执行，已编译组件继续在内存复用，不在业务调用中重新编译。

调试构建仅对 Wasmtime／Cranelift 的主要编译器依赖开启 Rust 优化，应用自身继续保留原有调试配置。加载诊断分别记录引擎创建、文件读取、编译／缓存命中及初始化耗时；缓存命中不能代替初始化和权限校验。冷、热加载性能以相同组件和构建配置实测，不将编译耗时直接等同于总启动耗时。

### 启停与账号

账号卡片通过 `adapter_list` 获取来源，`music_current_account` 与 `music_accounts` 实时读取当前选择和保存账号，不缓存、不返回凭证；账号来源切换丢弃旧响应。退出仅取消当前来源的选择，保留记录和系统凭证；删除账号才清理凭证。两种操作沿用账号代次和 `music-account-changed` 通知，使旧请求和查询缓存失效。

聚合账号登录页沿用同一账号读取和事件路径，仅为当前选择的适配器生成二维码并轮询；切换来源或离开页面时停止轮询、丢弃旧登录结果。账号头像通过 `useCoverImageSource` 复用有界图片缓存与图片失败回退策略。

适配器列表、启停及重载经 nativeCall 实时调用，不加入查询缓存。`musicAdapterEnabledV1:<source>` 是设备设置，保存在现有 SQLite settings，停用重启后保持；账号切换与缓存清理不删除它。保存失败不改变运行启停。成功变更发出 `adapters-changed` 与 `music-changed`，清理查询缓存并推进实例代次；nativeCall 与插件 Rust 歌曲缓存继续在命中/发布时复核来源上下文，旧查询及预加载不能发布。停用保留账号和队列，歌词磁盘缓存不删除，既有资源/本地缓存策略继续有效。

## 运行时缓存的接入

独立音源搜索不进入查询缓存；音源实例、查询条件变化后拒绝旧页，封面沿用显式域名授权及既有缓存。音源取址不保存普通 URL 缓存，预加载沿用最多 60 秒资源租约并复核平台账号／实例及音源实例代次。当前队列条目的手动选择仅存在播放 Actor 内存，移除、替换队列和重启后清理；契约与范围见 [独立音源适配器](resource-providers.md)。

完整平台适配器作为其他平台的音源时，复用上述取址和资源租约流程，并使用提供者自己的账号上下文、实例代次与解析并发预算。原曲平台和提供者的账号／实例在请求中持续复核、资源交付和预加载消费时再次复核；任一失效即拒绝旧结果。描述符及功能描述仍通过实时适配器列表读取，不新增查询或磁盘缓存。

整组播放请求先以 `Command::Collection` 交给播放核心，核心持有有界的单个歌单准备任务和请求代次。已有歌曲 key 时立即从曲库核对并进入 Loading／音源解析，完整歌单在后台补齐；无已知目标时先发布 Loading，再获取歌单。新队列、跳转、停止、清空、暂停或队列编辑会取消旧准备，迟到结果不得替换队列或发布错误；补齐前复核来源／账号作用域。补齐只更新队列与当前索引，保留音源、进度和播放 revision；失败保留已选曲目并报告歌单准备错误。临时单曲队列准备期间暂停无缝预加载，避免提前绑定错误的下一首。歌单准备继续沿用 MusicService 的 1000 首上限与 12 秒预算，不缓存临时播放地址。

前端资源读取统一调用 `app/src/lib/player.ts` 的 `nativeCall`。`app/src/lib/runtime-cache.ts` 使用 lru-cache 实现 10 分钟 TTL、LRU 容量限制和同键并发请求合并；读取不延长 TTL。页面组件保留展示状态，资源缓存由统一入口管理。

- 查询键由命令与排序后的参数组成，搜索词、分页偏移、收藏类型和 ID 都属于键。`refresh` 是刷新指令，从键中排除，调用前删除对应结果。
- 搜索建议 `search_suggestions`（最多 5 条）和分类搜索 `search_collections`（每页 30 条）复用统一查询缓存与账号失效规则；关键词、类型和偏移进入键。建议输入防抖 250 毫秒，输入变更、失焦或切换本地搜索后丢弃旧响应，失败不缓存且不阻塞直接提交关键词。
- 音乐库预览、歌单/专辑/艺人列表和详情、听歌记录、搜索、本地曲库、喜欢歌曲 ID、歌曲详情和歌词进入查询缓存。账号切换或退出清空查询缓存，包括未完成请求；过期查询重新获取。首页可通过 `peekMusicLibrary` 先展示旧预览，再获取新结果。
- 歌手／专辑详情 `music_entity_detail`、歌手专辑 `artist_albums` 和歌手歌曲 `artist_tracks` 复用查询缓存，类型、ID 与分页偏移进入键。歌手最新发布与专辑 tab 共用首批专辑；历史歌曲缺少结构化 ID 时，仅点击名称后查询 `song_information`，不逐行预取。本地歌曲通过本地艺术家/专辑索引跳转，绑定的网易云 ID 仅用于歌词关联。
- 收藏专辑接口不提供发行日期；缺少日期的专辑卡片仅在进入可见区域后通过 `music_entity_detail` 补齐，与专辑详情页共用缓存和并发合并。列表已提供日期时不补查，收藏时间 `subTime` 不作为发行日期；补查失败保留未知状态，再次进入页面可重试。
- 封面通过 `useCoverSource` 获取，同一 URL 的内容使用独立图片缓存。在线封面由适配器提供 `small / normal / large / exlarge / original`，宿主仅按场景选择，不生成缩放参数：列表、播放栏、头像与侧栏用 small，卡片用 normal，详情头图与 FM 用 large，全屏主封面用 original，列表封面在视口附近才加载；全屏播放器封面使用 eager 模式，绕过可见性检测和浏览器懒加载，避免进入动画期间停留在占位状态。账号切换保留这些公开图片。失败尝试更小档位，最后回退原图。
- WebUI 封面缓存容量 48MiB，原图与缩略图按最终 URL 共用预算，音乐查询缓存仍为独立 48MiB。模糊背景用 small，仅在启用、活跃且可见时加载。封面与专辑背景通过 `useCoverImageSource` 接收图片加载错误：缓存图片解码／加载失败时删除对应缓存键并尝试更小档位，最后回退原图；原图也失败才显示占位。原图主动加载失败时反向尝试缩略图，缓存候选不循环请求，最终原图允许一次直链重试；重新进入可见区域或重新打开页面会重试获取，不在错误回调中循环请求。缓存内容是完整 data URI，TTL 到期或容量淘汰不会使组件已持有的图片失效；后续读取过期键重新请求。
- `runtime_cover_access` 在 WebUI 缓存读取前与交付前实时核对已启用适配器的封面域名及实例状态，不进入查询缓存。`runtime_cover` 在原生缓存命中及网络交付前同样复核，不再硬编码网易云主机。`runtime_cover` 与 Android MediaSession 共用 Rust Moka 封面缓存，按请求 URL 合并并发加载，TTL 10 分钟、编码内容权重上限 32MiB；沿用宿主 HTTP 连接池、8 个并行请求和单张 4MiB 上限，失败不缓存。WebUI 图片解码失败通过 `runtime_cover_invalidate` 同步清除原生缓存。Windows SMTC 与 Android 媒体封面选择 exlarge，由适配器决定像素与地址，当前曲目保留一张，切歌后拒绝迟到结果；本地封面仅读取宿主封面目录中的既有文件。
- Android 系统歌词复用既有歌词服务、缓存与 AMLL 解析，不新增持久缓存或独立网络来源；原生只保留当前曲目的行时间轴，最多 5000 行、正文及辅助文本合计 1MiB、每个文本字段最多 4096 字节。切歌后清空并拒绝旧曲目结果，正常播放以 250ms 检查当前行，仅行内容变化时发布元数据，暂停停止计时。以上为实现上限，尚非后台耗电实测结论；vivo 卡片显示仍未通过验收。
- 查询和封面分别设条目数与序列化大小上限。大小是 UTF-16 序列化长度估算，既不是堆内存测量，也不包括图片解码、组件持有的数据或正在进行的请求。
- 发现页歌单、分类、私人雷达信息和每日推荐／FM 曲目复用同一查询缓存；歌单的分类、排序和分页偏移进入键。账号切换清空个性化结果；FM 打开及播放到队列倒数第二首时以 `refresh: true` 获取新批次，补歌跟随全局播放快照，与发现页生命周期无关；同一 FM 会话串行补歌，队列编辑后由播放核心作废会话并拒绝旧批次追加，失败不循环重试，可手动重试或切到下一首后重试。FM 队列沿用 1000 首上限，自动补歌超限时只淘汰已播放的历史。成功“不喜欢”使推荐曲目缓存失效，失败保留原结果。推荐歌单首批最多 30 条，后续按每页 30 条追加全部分类的热门歌单（列表偏移 30 对应热门接口偏移 0）；按歌单 ID 对当前查询展示结果去重，不修改缓存页。广场每页 30 条，推荐曲目最多 100 首，封面继续通过 `Cover` 懒加载与统一图片缓存读取。
- 查询失败、部分失败的喜欢预览、未取得歌词的空结果可重试。登录轮询、会话检查、设置读取、播放命令及临时音频地址直接执行；播放资源由播放核心按需解析。
- 收藏歌曲或删除歌单歌曲成功后，资源缓存仍按写操作规则失效；已打开的在线歌单把刷新代次与查询身份分开，后台重新读取已加载的分页范围，期间保留歌曲、详情和搜索／排序状态。完整结果返回后按歌曲 key 与元数据对比，复用未变化的歌曲对象和虚拟行标识；新增、删除、重排和元数据变化按新结果更新，失败保留旧列表并允许重试整个已加载范围。切换歌单或账号仍立即隔离旧查询，不沿用上一查询的展示状态。
- 发现页一言通过 `nativeCall("discovery_hitokoto")` 读取，复用查询缓存的 10 分钟 TTL 与并发合并。使用独立于网易云账号的公开 Hitokoto 接口，单次请求限时 3 秒、响应最多 16KiB；错误和无效内容不缓存，由页面显示默认文案，再次进入可重试。
- 音乐库喜欢卡片按顺序尝试预览中的前两首歌曲，复用 `loadLyrics` 与歌词来源设置；无可用歌词或读取失败后查询同一 `discovery_hitokoto` 缓存。全部失败显示缺失／读取错误与一言失败原因，页面离开或候选歌曲变化后停止后续请求并丢弃旧结果。

接入新功能的步骤：

1. 从 `nativeCall` 调用现有资源命令；资源读取新增命令时，在 `cachedCommands` 中登记，并确认所有影响结果的参数进入键。完成标准是重复及并发读取只触发一次底层请求。
2. 歌单添加歌曲成功后使喜欢歌曲 ID、音乐库预览、收藏列表和歌单详情失效；编辑信息成功后同时失效发现页歌单与实体详情，删除成功后失效发现页歌单。收藏弹窗复用按每页 30 条读取的 `library_collections`，分页遍历自己的歌单并按 ID 去重，仅渲染视口附近的条目。歌单移除歌曲成功后使收藏状态、音乐库预览、收藏列表和歌单详情失效；移除队列项只更新播放状态，不影响资源缓存。写操作成功后在 `nativeCall` 的影响表中登记相关读取命令。完成标准是成功写入后获得新数据，失败保留原缓存，写入前的未完成请求无法重新填回旧数据。
3. 涉及账号切换时复用 `resetAccountCache`；涉及后台更新时复用既有事件失效路径。完成标准是旧账号结果不会进入新账号页面。
4. 给刷新入口传入 `refresh: true`，或显式使用 `invalidateNativeCache`。资源适用本文已有策略时复用这一入口；确有不同生命周期时，在本文记录原因、容量与失效规则。

快捷键开关和绑定以 `nons-shortcut-settings` 保存在 WebUI localStorage，默认关闭、六项绑定均为空；启动恢复注册，停用解绑但保留绑定。注册失败先清理部分注册再恢复旧绑定，成功后才保存，录入与清除绑定自动生效，无需手动保存。绑定仅接受一至三个修饰键与一个普通键，旧单键或无效绑定恢复时清空；录入期间串行解绑，结束或离开页面后恢复。它们属于用户设置，不加入资源缓存；收藏复用账号入口与既有写入失效规则。

Windows 私有音频运行时的插件注册缓存位于应用缓存目录 `gstreamer-registry.bin`，由 GStreamer 根据插件文件位置与时间自动失效；它不存储音乐或歌词，不接入资源查询缓存和 TTML 清理入口。

顶部网易云搜索历史以 `nons-search-history` 保存在 WebUI localStorage，只记录实际提交的非空关键词，去重后按最近搜索顺序保留 10 条；重复搜索置顶。本地曲库搜索不写入此历史。历史属于设备上的用户数据，不加入资源查询缓存，不随账号切换或缓存清理失效；存储不可用时在当前会话内保留，恢复时忽略损坏或无效记录。

歌单侧栏复用 `library_collections` 的分页与统一资源缓存，打开时重新读取，创建歌单沿用写操作失效规则。最近打开的在线歌单以 `nons-recent-playlists:<userId>` 按账号存入 WebUI localStorage，重复打开置顶，最多保存 20 条，侧栏显示最近 2 条；切换账号不把上个账号仍显示的详情记入新账号历史。此历史属于用户导航数据，不加入资源查询缓存，清理缓存时保留；恢复时校验记录并丢弃损坏数据，存储不可用时保留当前会话记录。

播放栏显示方式以 `nons-playback-bar-mode` 保存在 WebUI localStorage，默认折叠式，可切换常驻式或关闭；存储不可用时在当前会话内保留，损坏或未知值回到默认。此项属于设备界面设置，不加入资源缓存，不随账号切换或缓存清理失效。随机播放开关与有界随机索引顺序随播放快照保存；不改变歌曲列表顺序，恢复时校验索引完整性。

播放进度沿用 SQLite `player` 快照，每 5 秒保存一次，正常退出时再次保存；属于播放持久状态，不加入查询缓存。启动恢复当前歌曲与进度并保持停止状态，点击播放后重新解析资源，在暂停预备完成后定位再出声；已播完的歌曲从头播放。切换歌曲从零开始；恢复时校验当前索引并按已知时长限制位置，未知时长保留上次管线测得的时长。加载与待定位期间不让管线的初始零位置覆盖待恢复进度。

## 歌词运行时与磁盘缓存

更新状态与更新清单通过 `nativeCall` 直接读取，不进入音乐资源查询缓存。签名更新包仅保留一个受 512MiB 上限约束的临时文件，安装或正常退出时失效，不参与音乐缓存清理。

Rust 歌词服务位于 `lyrics.rs`。所有歌词格式的运行时结果保存在曲库连接的 SQLite TEMP 表中，使用内存临时存储，成功结果 10 分钟过期。已确认缺失的标记保留 24 小时，网络错误只退避 30 秒；这两项沿用歌词来源约束，均不写入磁盘资源缓存。

全屏歌词显示状态同时绑定歌曲 key 与播放核心的 revision；切歌或重新播放时，第一帧即隐藏上一播放代次的歌词。查询完成、错误与后台更新写入前读取实时播放快照进行核对，不依赖 React effect 的清理时机；本地与流媒体歌曲即使标题相同也保持独立。WebUI 查询缓存继续按歌曲 key 与来源跳过参数区分。

全屏歌曲菜单直接显示已应用歌词的来源；刷新复用 `loadLyrics`，在线路径传入 `refresh` 清理对应缓存并推进后端代次，本地路径每次重读文件。手动刷新推进界面请求代次，旧查询不能覆盖新结果；刷新期间保留已有可用歌词并禁用重复刷新，切歌或修改来源后丢弃旧刷新交付。收藏、复制和详情复用 `SongActionsProvider`，平台收藏只作用于真实网易云曲目，本地绑定 ID 不作为流媒体歌曲身份。

全屏播放器的封面、控制区和加载占位同步显示，AMLL 渲染器与动态背景延后至进场动画完成后加载和初始化；退出开始立即卸载歌词渲染器、暂停背景动画，背景保留至退场完成再销毁。歌曲存在时固定两栏布局，歌词查询复用原缓存与失效规则，不因加载、缺失或模块下载改变封面位置。此调度旨在减少动画期间的初始化工作，尚未据此宣称实际帧率提升。

TTML 持久化统一由 `ttml_cache.rs` 的 `TtmlCache` 管理。`cache_result` 在同一锁内检查请求代次、更新运行时结果并按开关写入 TTML。清空、配置变更及手动刷新推进代次，旧网络请求不能重新填充已清空的缓存。磁盘写入失败不阻塞在线歌词回退。

磁盘缓存只保存有效 TTML，当前由 AMLL 在线查询产生；QQ QRC/LRC 与网易云 LRC/YRC 留在运行时缓存。在线歌词继续复用现有运行时和 TTML 磁盘缓存。

`lyricSources.localSource` 保存本地歌曲的“本地／在线”来源选择，旧设置缺少此字段时默认在线；流媒体歌曲始终走在线入口。本地与在线之间不自动回退。`local_track_lyrics` 经 `nativeCall` 实时读取，不进入 WebUI 查询缓存、Rust 运行时歌词缓存或 TTML 磁盘缓存，每次加载重新读取音频内嵌歌词及同目录同名 LRC。内嵌文本不可用或解析失败时可跳过内嵌文本再次读取 LRC，两个本地读取阶段均不调用在线服务。普通音频标签读取跳过音频属性和封面，NCM 复用已有流式解密标签读取。正文上限 2MiB，UTF-16 解码后的 UTF-8 文本同样检查上限，最多两个并行阻塞读取任务。文件更改在下次读取时生效，暂不主动监听歌词文件。来源选择变更沿用现有设置保存与在线缓存代次失效；界面同时核对播放 key、revision 和来源设置快照，拒绝迟到结果及不适用的后台在线更新。

QQ 和网易云搜索歌词缓存键使用完整曲目元数据与本次艺术家分隔符配置的 SHA256，标签、绑定或分隔符变化不会复用旧匹配结果；QRC 优先路径使用 `qq:qrc-v3:`，前端解析失败后的 LRC 路径使用 `qq:lrc-v3:`，网易云搜索使用 `netease:search-v1:`，避免 QRC 解析失败时重新命中同一内容。`skipQrc` 进入 WebUI 查询键；手动刷新同时清理两种 QQ 路径、AMLL、网易云 ID 取词与网易云搜索路径。搜索结果连同匹配分存入既有有界运行时缓存，沿用 10 分钟成功期、24 小时确认缺失期、网络错误仅退避 30 秒及请求代次失效；低于 80 分的 QQ 成功结果保留并与网易云备用结果比较，不记为缺失。成功结果缓存 10 分钟，过期内容立即显示并后台刷新。确认未匹配到候选曲目或无歌词时缓存 24 小时，搜索/取词网络错误、解码错误和超时只退避 30 秒，然后继续网易云；QRC 失败后先尝试匿名 GetPlayLyricInfo，再回退旧 LRC；已有 QRC 仅补充缺失译文与发音，不替换逐词原文，补充后的总正文仍限制为 2MiB。补取预算在 QQ 总计 6 秒内，为旧 LRC 保留最多 1400 毫秒；有可用 QRC 时预留交付时间，避免补取超时丢弃原文。QRC/LRC 优先路径分别使用 v3 缓存键，避免复用旧回退链产生的纯原文。任一 QQ 路径成功的结果按成功结果缓存。来源设置以 `lyricSources` 持久化；成功更改推进缓存代次、清空运行时歌词及退避状态，并通过 `nativeCall` 使 WebUI 的所有 `track_lyrics` 结果失效。已有 TTML 磁盘文件保留，关闭 AMLL 时跳过读取；旧请求不能重新写入缓存或覆盖新设置下的显示结果。全屏歌词与音乐库摘录在来源开关变化时重新取词。

用户选择的是缓存父目录，应用使用专属目录：

```text
<选择的目录>/nons-cache-v1/
├── index.sqlite3          # 来源、格式、过期时间、访问时间与字节数
└── lyrics/ttml/
    └── <SHA256(缓存键)>.ttml
```

默认父目录采用系统应用缓存目录。容量默认 64MB，可设置 1–4096MB，另设 2000 条记录上限，达到上限按最久未使用淘汰。占用统计指 TTML 内容字节数；小型索引数据库另占空间。清空和迁移只处理索引中的歌词文件，用户选择的父目录及原始音频文件保留。

TTML 新鲜期为 10 分钟，过期仍可立即显示并后台更新；更新失败保留旧内容，以支持离线读取。关闭磁盘缓存停止持久化读写，已有文件保留，运行时缓存继续使用。更换目录迁移已有有效 TTML，规范化后的同一目录不迁移。历史数据库中的有效 TTML 在启动时迁移，旧 LRC/YRC 与缺失标记移除。

本地音频的内嵌封面是曲库导入产生的元数据资产，沿用独立 `covers` 目录及既有容量限制，不属于此 TTML 清理入口。音频通过播放管线传输，本次不持久化歌曲音频。

## 本地目录与曲库

字体选择通过 `nativeCall("system_fonts")` 按需读取系统字体族名，使用 font-kit 的平台后端，不读取字形数据、不复制字体文件。两个选择器共用既有 WebUI 运行时 LRU（10 分钟 TTL、512 项和 48MiB 上限），失败不缓存；“重新读取”跳过旧缓存，安装字体后重新打开设置或重启可在缓存过期后刷新。应用字体和歌词字体以 `nons-font-settings` 保存在 WebUI localStorage，启动渲染前恢复；恢复默认不删除资源缓存。字体卸载或缺少字形时使用系统后备字体，保留用户选择。

`LocalFolders` 统一保存最多 32 个目录，用 notify 递归监听文件变化。启动与新增目录触发后台扫描；通知合并后串行扫描，未变化文件按大小和修改时间跳过标签解析。扫描错误保留此前索引，手动重新扫描用于补偿错过的通知。

`local_origins` 记录曲目与导入来源的多对多关系：管理目录使用规范化绝对路径，单独打开的文件使用独立来源。完整扫描结束后移除该目录下已不存在的记录；移除目录只移除其来源关系。其他目录或单独打开仍引用的曲目继续留在曲库，播放队列持有的曲目保持可播放；原始文件保留。旧版本的一次性导入记录作为独立来源保留，添加同一目录不会自动改变其归属。

NCM 与其他音频共用扩展名筛选、目录监听、原路径曲库标识和大小／修改时间失效规则。索引直接用流式解密 Reader 交给 Lofty，不生成旁置音频；标题、歌手、专辑、歌词关联 ID 与内嵌封面可由 NCM 容器补充，已有显式歌词绑定优先。封面复用本地封面目录及其 32MiB 上限，歌曲和歌词查询仍走 `nativeCall`。

播放 NCM 在阻塞线程解码到系统临时文件，单文件 256MiB，最多 4 个存活文件（合计最多 1GiB）与 2 个解码任务；当前音频和预加载音频持有文件生命周期，停止、切换与正常退出释放。弱引用按原路径、大小和修改时间复用仍在使用的文件；源文件改变不复用旧结果。不持久化播放缓存，异常退出可能遗留临时文件，由系统临时目录清理。不会在原目录生成 MP3／FLAC。

独立转换文件属于用户保存的音乐，保留原 NCM，不纳入资源缓存清理；已管理目录的原监听照常收录转换结果并使本地查询失效。文件转换和权限查询不加入 WebUI 查询缓存，每次重新检查插件代次、权限与授权根。转换最多 2 个并行任务，按 32KiB 块验证句柄；同目录临时文件完整写入标签后原子发布，同名失败不覆盖，失败清理本任务创建的临时文件。

目录变更发出 `local-library-updated`：管理弹窗更新数量和状态，音乐工作区在扫描完成后使本地查询和歌词缓存失效并重载列表。显示本地封面的设置影响列表、播放栏和歌词封面背景，统一通过 `useCoverSource` 生效。

全量扫描期间仍需遍历路径及检查文件属性；跳过标签解析、通知合并、有界队列与图片懒加载是设计上的成本控制。实际冷启动、内存和大型曲库扫描耗时需在明确环境与曲库规模下测量。

### 本地浏览、歌单与元数据

`local_entities` / `local_entity_detail` / `local_entity_tracks` / `local_track_information` 通过 `nativeCall` 复用统一查询缓存。实体列表每页 30 个，歌曲每页 100 首；额外读取一条判断续载，歌曲列表虚拟渲染，整组播放最多 1000 首。艺术家与专辑关联在 SQLite 索引中维护，设置分隔符时在事务中重建，不逐页加载完整曲库到 WebUI。

本地搜索页分别持有音乐、艺术家和专辑的分页状态，“所有”和单分类视图共用结果，切换分类不重发首批查询。三类均成功完成且无结果时隐藏搜索分类导航并显示统一提示；加载中与失败不视为空结果。关键词或曲库刷新代次变化时重新创建搜索视图，旧请求沿用分页查询的代次隔离。

`local_entities` 保存首次遇到艺术家时的封面，重扫、重启和标签更新不改头像。专辑键由专辑名与专辑艺术家组成，缺少专辑艺术家时使用原始艺术家标签；详情按碟号、音轨和标题排序。旧曲目首次迁移按既有插入顺序建立索引，下次扫描为缺少技术元数据的记录补读标签。`local_metadata` 保存 Lofty 读取的音轨及音频属性，详情弹窗按需在阻塞线程重读文件，失败可重试。

本地歌单及歌曲顺序保存在独立 SQLite 表中，与在线账号、歌词资源缓存无关；最多 200 个歌单，每个 10000 首，加入时去重，只接受本地歌曲。删除歌单只删除其关联，移除目录后不显示已退出曲库的曲目，重新收录同一路径可恢复对应歌单关联。成功写入通过 `nativeCall` 和 `local-library-updated` 清理本地读取缓存并刷新页面，失败保留缓存。

`localPreferences` 保存最多 16 个普通文本分隔符（每个最多 32 字节），空列表视为单一艺术家。更改时推进歌词服务缓存代次并清空运行时结果，保留 TTML 文件；前端重新取词，旧响应不得更新新偏好下的页面。在线解析失败可跳过已失败来源并继续下一在线来源，在线歌词异步刷新只更新当前已采用的同一来源。

## 插件下载文件

网易云下载插件的任务记录使用自身 storage 分区（最多 32 项）；配置复用修订快照，账号凭据使用系统凭据库并在卸载时清理。任务记录不持久化 Cookie 或临时资源 URL。传输与进度不加入查询缓存，每次验证插件代次和权限。下载使用外部读写授权根，与播放缓存独立；缓存清理、插件卸载和目录授权撤销不删除已完成的外部音频文件。已有本地音乐目录继续使用原变化同步与缓存失效规则。

## 基础音乐适配器接线（ADR 0006 阶段二）

当前来源与补充来源顺序作为设备偏好保存在 SQLite 设置 `musicSourcePreferencesV1`，与账号、播放队列和资源缓存独立。`music_source_preferences` 每次读取实时状态，不进入 `nativeCall` 查询缓存；写入核对修订号，先写盘再发布新值及 `music-source-preferences-changed`。切换角色不推进来源会话或适配器实例代次，不撤销已交付音频。停用或缺失的已保存来源保留，显式新选当前来源必须已注册且启用。账号登录／选择成功后通过 `music_source_intent`／`music_use_source` 检查独立用户操作代次，再切换工作区；较新的明确操作阻止旧登录抢回来源，启动恢复与自动刷新不切换。来源操作与登录挑战实时处理、不加入查询缓存；`music_cancel_login` 撤销挑战，后端凭据写入同样核对取消状态。

聚合搜索复用 `music_query` 的作用域缓存与后端请求预算，每来源独立游标且最多一个在途分页。来源偏好、账号、实例与写入事件重新建立查询实例并拒绝旧交付；过滤来源复用同一实例内结果，不改变偏好。每来源每类型最多保存 1000 项，达到上限停止续载并提示；错误保留先前结果和游标，只由明确重试继续。临时播放 URL 不进入搜索结果。收藏整体播放按来源读取最多 10 页、1000 首，执行队列操作前复核初始作用域，拒绝混入账号／实例变更后的批次。

`music_queue_track` 按统一作用域读取单曲并保存到既有曲目表；`music_queue_tracks` 将已经读取的同来源统一元数据转为队列项，每批最多 100 首、2MiB，核对作用域后事务保存，两个操作均不进入查询缓存。通用在线项保存 `source.kind=online` 及完整 `MusicTrack`，key 使用引用的 JSON 元组编码，曲目表来源列使用真实平台；不保存临时播放 URL 或凭据。网易云仍沿用原 `netease:<id>` 与 DTO，本地记录不变；保存播放快照与重启读取兼容三种项。详情读取继续经 `music_query` 和现有作用域缓存，按来源／实体／游标隔离。实际跨来源解析通过统一播放服务与资源租约，不使用工作区当前来源改写曲目。

单曲查询沿用上述 Rust 有界缓存，不新增通用缓存或持久化元数据表。当前账号与实例作用域进入缓存条目的检查，清理资源缓存仍使原在途请求不能回填。在线播放地址不进入 `nativeCall`、单曲查询缓存或持久队列；统一管理器只登记最多 16 个后端资源所有权，并在账号／来源变化或过期时拒绝尚未交付资源。已交付播放核心的独立 HTTP 资源继续按音频管线读取。

本地 NCM 准备位于 `local/playback_resource.rs`，保持原文件统计复用、双解码任务及临时文件生命周期规则。播放解析预算、响应上限和阶段三迁移注意事项见 [音乐适配器记录](music-adapters.md#阶段二修改记录与注意事项2026-10-10)。

## 统一音乐业务与账号缓存（ADR 0006 阶段三）

WebUI 在线读取统一经 `ScopedMusicQueries`：兼容网易云命令与 `musicClient` 共用入口，先读取 `music_context` 再以完整作用域构造缓存键，返回与缓存命中交付前再次验证。作用域由宿主序列化的 `[SessionContext, 适配器实例代次, 写代次]` 组成；只允许同会话、同实例下的普通读取恢复，未知作用域格式不推测身份。缓存清理、单键刷新和容量淘汰由 `RuntimeCache` 统一转换为 `CacheInvalidatedError`；失效覆盖等待结果与异步交付验证期间，旧请求不能交付或回填。缓存项刷新不等于账号重置：后者使用 `context` 失效原因推进上下文代次，即使作用域字符串相同也拒绝旧调用。

同身份写入或缓存刷新后，普通在线读取最多尝试三次，每次重新核对作用域并合并同键请求；真实请求错误不自动重试。账号切换、来源停用／重载拒绝旧读取；带旧游标或非零 offset 的续载不得跨写代次重放，由页面重建分页；入队操作不重放。独立歌词、本地信息与封面维持原失效策略、容量和 TTL，不绑定在线身份，也不加入上述自动恢复。

`music_query` 与 `music_read_track` 复用 nativeCall 的现有有界查询缓存；参数含稳定来源、实体引用／完整业务请求和 `music_context` 返回的会话／实例／写代次作用域。宿主 musicClient 在缓存命中前后复核作用域，旧在线命令也执行该检查；停用来源后已缓存元数据不能作为成功结果返回。本地信息、一言、字体和独立歌词不绑定网易云作用域。

成功统一写入推进来源写代次，拒绝写前在途查询的旧响应，并发出 `music-changed`；账号变更发出 `music-account-changed`。前端统一监听并清理查询缓存，账号 Provider 重置喜欢与异步状态；选择／删除账号、登录／退出沿用失效入口。统一客户端写入保守清空现有查询缓存，兼容旧写入仍使用原影响表，失败不清理成功缓存。歌曲元数据继续复用 Rust 原 128 条缓存，键为 EntityRef、命中和回填复核账号、实例、写入和清理代次；不缓存临时播放地址或凭据。

系统凭据与 `musicAccountsV1` 是账号持久数据，不是资源缓存，清理资源缓存不删除它们。账号删除／退出的墓碑、失败恢复和 Windows 旧 password 编码处理见 [适配器阶段三记录](music-adapters.md#阶段三修改记录与注意事项2026-10-10)。公开封面继续保留，歌词保持既有专用失效与来源回退，不增加第二套歌词缓存。

## 启动展示预览

`account_profile_snapshot` 实时读取宿主当前选中的保存账号，仅返回展示信息，不做网络验证、不返回凭据。界面先恢复展示，再调用既有 `account_profile` 验证；账号变更推进请求代次，旧响应不得发布。来源状态通过共享 store 统一读取与订阅，合并并发刷新，不作为权限判断缓存。

音乐库保留上次成功读取的首页摘要（最多 12 首喜欢歌曲）和首批全部歌单（最多 30 项），使用 `nons-library-preview-v1` 本地展示预览。每账号按 JSON UTF-16 长度估算最多 128 KiB，最多两个账号，有效期 24 小时；不保存图片字节、凭据、播放地址或本地目录。只有宿主确认当前账号后才读取对应预览，账号切换隔离展示；页面仍通过 `nativeCall` 及统一查询缓存获取当前内容。成功空列表替换旧展示，刷新失败保留已有展示并显示错误；音乐变更和音乐库写操作清除预览。存储不可用、超限或内容无效时退回骨架，不阻塞启动。

封面与插件前端任务在首次绘制后启动，隐藏窗口以 200ms 调度兜底，组件卸载取消尚未开始的任务；后续交互立即执行。播放核心初始化与音频播放不延迟。全屏播放器采用按需加载，隐藏页面不启动歌词渲染；打开在线收藏详情不触发无关音乐库首页请求。
