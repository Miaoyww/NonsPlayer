# 独立音源适配器

2026-10-15 实现。沿用 ADR 0008 的曲目平台／资源提供器分离，以及 ADR 0009 的统一 WASM Component 与通用 Host。音源由 AdapterManager 独立注册，不重复注册 `netease`／`qqmusic`，不进入账号或工作区来源列表。

## 契约与生命周期

Rust 契约位于 `packages/music-adapter-sdk/src/provider.rs`。`ResourceProviderDescriptor` 包含独立 `id`、显示名称、契约版本、支持解析的 `platforms`、支持搜索的 `searchPlatforms` 和公开封面域名。搜索平台必须是解析平台的子集；本地音乐不参与在线音源解析。

Component 继续使用现有 initialize／shutdown／call transport；独立音源导出以下方法：

| 方法                        | 输入                                                           | 输出                                   |
| --------------------------- | -------------------------------------------------------------- | -------------------------------------- |
| `music.resource-descriptor` | `null`                                                         | `ResourceProviderDescriptor`           |
| `music.resolve-resource`    | `{request: ResourceRequest, session, adapterGeneration}`       | `{metadata, url, headers}`，仅后端消费 |
| `music.search-resources`    | `{request: ResourceSearchRequest, session, adapterGeneration}` | `{items: MusicTrack[], nextCursor}`    |

返回沿用 `{status:"ok",data}`／`{status:"error",data:MusicError}`。`session` 是 Host 绑定的音源执行身份，不是被解析歌曲的平台账号；歌曲真实平台在 `request.track.reference.source`。资源请求包含完整通用曲目元数据、首选音质和是否允许降级，不向音源交付原平台账号凭据。

随包描述使用 `resourceProvider` 与 `permissions`，和完整平台包的 `descriptor` 互斥。当前独立音源可使用通用 HTTP、系统时间与随机数，不授予账号凭据、状态存储或 WebSocket。外部任意包安装和原始洛雪脚本导入不在本次实现范围。实例加载中／加载失败在适配器设置中分别显示；失败不阻止其它有效包加载。

每个音源最多 4 个搜索、2 个解析并发，最多注册 16 个；沿用适配器 Component 大小、内存与 transport 预算。启停设置保存为 `resourceProviderEnabledV1:<id>`，停用推进实例代次；在途请求和预加载资源检查音源实例及可用平台的账号／实例代次，取消或失效不再发起后续尝试。

## 播放选择

自动模式先请求曲目平台；获取、校验失败后，按音源 ID 的稳定顺序逐个尝试支持该平台且已启用的独立音源。每项最多尝试一次，整组总期限 24 秒，单项解析仍最多 12 秒；取消、账号或实例失效终止整个旧请求。平台停用保留既有停用语义，不借备用音源绕过。此处覆盖资源解析与交付前校验；已经交付给音频管线之后的解码、输出设备或传输中断不自动重新选源。

选择某个音源后先尝试该音源，失败再尝试官方及其它音源。选“官方”表示官方优先，仍保留获取失败后的回退；选“自动选择”清除当前条目的手动选择。音质降级遵守已有设置，试听和未知完整性的资源不能声明为完整播放。

全屏播放器“歌曲来源”提供同平台音源选择，以及搜索并手动选择其它平台歌曲。后者只替换当前队列条目的音频，保留原曲目身份、队列位置和收藏对象；展示实际音频的提供器、平台、标题和歌手，用户自行核对版本、专辑与时长。不会按歌名自动替换为另一平台歌曲。

选择仅保存在播放 Actor 内存，按队列条目 key 保存；替换／清空队列、移除条目及 FM 历史淘汰时清理。重启不恢复。切换保留当前进度；迟到的查询、选择及预加载不能覆盖新的播放代次。普通播放和无缝交接均更新播放归属；预加载下一首时不提前改变当前歌曲的归属。

开始尝试其它音源、成功变更、最终获取失败分别以状态提示明确表达；“歌曲来源”中可随时查看当前尝试或使用的提供器。URL、请求头和 API 密钥不进入队列或前端归属数据。

## 搜索与缓存

有搜索能力的已启用独立音源进入现有单曲聚合搜索及来源选择弹窗，每个平台独立分页、错误和重试。歌手／专辑／歌单分类不调用音源搜索。返回项必须包含真实平台和稳定 ID；搜索通道标识与曲目身份分开，不将音源 ID 写成音乐平台。

搜索游标绑定音源、实例代次、平台、关键词和页大小，变更后旧游标失效；结果有数量、正文大小上限，界面复用虚拟歌曲列表和滚动续载。音源返回未知时长时，优先复用已知曲库元数据；播放前通过原平台通用曲目接口补齐所选歌曲，不对整页结果逐首发起网络查询。聚合分组按真实平台计数，同一身份的晚到完整元数据可补齐先到的简略结果。音源搜索目前不加入查询缓存，关闭／变更查询后拒绝迟到结果；封面复用既有受控缓存，授权来自音源显式声明的封面域名。临时播放 URL 不写普通缓存，预加载资源沿用最多 60 秒的资源租约。

具体 GD音乐台（星海）能力和验收限制见 `adapters/gdstudio/README.md`。
