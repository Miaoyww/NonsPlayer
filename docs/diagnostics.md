# 诊断日志

开发和发布版本均输出本机日志。前端捕获后的 IPC 失败、未捕获异常与 Promise 拒绝会进入控制台和原生日志；Rust 音乐服务记录来源、操作、请求编号、耗时与结果码。取消与上下文失效记为 Info，真实失败记为 Error。网易云业务转换和 WASM 执行／诊断出口保留脱敏后的失败原因。

队列曲目写入失败的 IPC 错误包含 `code`、`message` 和 `stage`，`message` 保留脱敏后的原始存储错误。原生日志同时通过日志插件事件显示在浏览器控制台，不依赖页面是否显示错误。适配器公共错误契约保持稳定。

## 文件位置与容量

- Windows 便携版：程序目录的 `data/logs/nons.log`。
- 安装版及其他平台：Tauri `app_log_dir()` 下的 `nons.log`；启动日志输出实际目录。
- 单文件 2 MiB，保留最近 4 份轮转文件；时间戳为 UTC。日志不进入资源缓存，清除音乐缓存不删除日志。
- 文件日志无法初始化时保留终端和 WebView 输出，不阻止启动。前端上报失败会在控制台说明，不递归上报日志错误。

不记录完整请求／响应、账号凭据和鉴权地址。每条诊断限长并合并为单行；URL、JSON／数组正文及常见凭据字段后的内容被过滤。前端上报最多 16 个在途任务，原生入口每秒最多接收 64 条，WASM 诊断沿用已有每秒 16 条限制。音乐服务成功日志也受文件轮转容量限制。

排查时同时查看前端的 `command / source / operation / code / message / stage` 和相同时间的 `nons::music`、`nons::storage`、`nons_adapter_netease`、`nons::adapter` 日志。前端热更新不会更新 Rust 命令或文件日志配置，修改原生代码后需要重新启动开发应用。
